# Contain-Site

The public site for **Contain.**, an unofficial offline reader for the SCP Foundation wiki: <https://contain.vectorgarden.dev>

- `/`: what Contain. is
- `/privacy/`: the privacy policy (App Store Connect's Privacy Policy URL, and linked from the app)
- `/support/`: how to get help (App Store Connect's Support URL)

Plain static HTML, served by GitHub Pages from `main`. No build step. `CNAME` sets the custom domain, and `.nojekyll` turns off Jekyll.

**Support requests** go to this repository's issues.

The app's source is private. This repository holds only the site.
